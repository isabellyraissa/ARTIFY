# 🎨 ARYIFY

Plataforma digital desenvolvida para conectar **artesãos** a **clientes**, facilitando a divulgação e venda de produtos artesanais de forma simples e acessível.

## 🚀 Sobre o projeto
O ARYIFY surgiu com o objetivo de valorizar o trabalho de artesãos, oferecendo um espaço online onde eles podem expor seus produtos, alcançar mais pessoas e gerar renda.

A plataforma atua como um **marketplace**, promovendo a conexão entre quem produz e quem deseja consumir produtos únicos e personalizados.

## Objetivo
- Incentivar o empreendedorismo artesanal  
- Ampliar a visibilidade de pequenos produtores  
- Facilitar a comercialização de produtos artesanais  

## Funcionalidades
- Cadastro de artesãos  
- Exibição de produtos  
- Navegação por categorias  
- Interface simples e intuitiva  
- Divulgação de produtos artesanais
